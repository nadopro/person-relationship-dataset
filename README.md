# Historical Person Relationship Graph Dataset

This repository provides the experimental dataset used in the study
"Performance and Scalability Analysis of an API-Based Exploration System for Large-Scale Person Relationship Graphs."

## Dataset

The dataset consists of a normalized historical person relationship graph constructed from historical person relationship information and epistolary index data.

- Nodes: 84,908
- Relationships: 95,550
- Data format: JSON

Redundant and inverse relationships in the source data were normalized before constructing the experimental graph.

## Data Availability

The normalized experimental dataset used in this study is publicly available through this repository.
